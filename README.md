# Remotion Reel Generator

Универсальный генератор вертикальных Reels на React и [Remotion](https://www.remotion.dev/). Проект превращает набор текстовых сцен в готовое видео формата 1080×1920 — без видеосъёмки и без генерации видео нейросетью.

Ты описываешь тему, заголовки и пояснения, а Remotion собирает анимированный MP4. Подходит для образовательных роликов, карточек, объяснений, анонсов и коротких социальных видео.

## Как это работает

```text
src/content.ts  →  темы и тексты сцен
        ↓
src/Reel.tsx    →  дизайн, анимация, прогресс-бар
        ↓
Remotion        →  рендер видео
        ↓
out/*.mp4       →  готовый Reels
```

- **Контент** хранится отдельно в `src/content.ts`.
- **Дизайн и анимация** находятся в `src/Reel.tsx`.
- Чтобы сделать новое видео, обычно достаточно изменить только `src/content.ts`.

## Быстрый старт

### 1. Установи зависимости

```bash
npm install
```

### 2. Запусти Remotion Studio

```bash
npm start
```

Studio откроется по адресу:

```text
http://localhost:3000
```

В GitHub Codespaces открой вкладку **Ports**, найди порт `3000` и нажми **Open in Browser**.

### 3. Создай видео

Измени файл `src/content.ts`, затем собери MP4:

```bash
npx remotion render src/index.ts Reel out/my-reel.mp4
```

Готовый файл появится в папке:

```text
out/my-reel.mp4
```

## Как создать Reels на любую тему

### 1. Открой файл контента

```bash
src/content.ts
```

### 2. Измени массив сцен

Каждая сцена — один экран видео:

```ts
export const scenes: Scene[] = [
  {
    title: 'ИИ экономит время',
    subtitle: 'Автоматизируй рутину и сосредоточься на главном',
    color: '#2563eb'
  },
  {
    title: 'Пиши быстрее',
    subtitle: 'Проси ИИ подготовить первый вариант текста',
    color: '#7c3aed'
  },
  {
    title: 'Проверяй результат',
    subtitle: 'ИИ ускоряет работу, но финальное решение за тобой',
    color: '#16a34a'
  }
];
```

### 3. Поля сцены

| Поле | Назначение | Рекомендация |
|---|---|---|
| `title` | Крупный заголовок экрана | 2–5 слов |
| `subtitle` | Пояснение под заголовком | 1–2 коротких предложения |
| `color` | Цвет акцентной полосы | HEX-код, например `#2563eb` |

### 4. Настрой длительность

Открой `src/Root.tsx`:

```tsx
<Composition
  id="Reel"
  component={Reel}
  durationInFrames={750}
  fps={30}
  width={1080}
  height={1920}
/>
```

Формула:

```text
длительность в секундах × 30 = durationInFrames
```

| Длительность | `durationInFrames` |
|---:|---:|
| 15 секунд | 450 |
| 20 секунд | 600 |
| 25 секунд | 750 |
| 30 секунд | 900 |

Все сцены автоматически распределяются на общую длительность видео.

## Шаблон промпта для нового видео

Дай ИИ-агенту такой запрос:

```text
Создай массив scenes для Remotion-видео на тему: [ТЕМА].

Правила:
- 5 сцен.
- title: максимум 5 слов.
- subtitle: 1–2 коротких предложения.
- color: разные HEX-цвета для каждой сцены.
- Тон: образовательный, понятный, без кликбейта.
- Формат ответа: только массив scenes на TypeScript.
```

Пример:

```text
Создай массив scenes для Remotion-видео на тему:
«Как защитить аккаунт от фишинга».
```

Полученный массив вставь в `src/content.ts`, проверь ролик в Studio и отрендери MP4.

## Правила пользования

1. **Создавай только законный и этичный контент.**  
   Не используй проект для распространения дезинформации, мошенничества, дискриминации, вредоносных инструкций или материалов, нарушающих права других людей.

2. **Проверяй факты перед публикацией.**  
   ИИ может ошибаться. Ответственность за точность, контекст и последствия публикации остаётся за автором видео.

3. **Не храни секреты в репозитории.**  
   Не коммить API-ключи, токены, пароли и файлы `.env`.

4. **Не коммить временные файлы.**  
   Папки `node_modules/`, `out/` и `.remotion/` должны быть в `.gitignore`.

5. **Уважай лицензии.**  
   Использование Remotion регулируется его собственной лицензией. Проверь актуальные условия перед коммерческим использованием, автоматизацией или массовым рендером.

6. **Экономь ресурсы Codespaces.**  
   После работы останавливай Codespace: **Codespaces → Stop**.

7. **Меняй контент через `content.ts`.**  
   Не редактируй анимацию ради обычной смены темы: это упрощает поддержку и снижает риск ошибок.

8. **Делай изменения через ветки.**  
   Для новых видео или правок дизайна создавай отдельную ветку, проверяй результат в Studio и только затем объединяй с `main`.

## Рекомендации по хорошим Reels

- Одна сцена — одна мысль.
- Текст должен читаться за 3–5 секунд.
- Начинай с проблемы, вопроса или обещания пользы.
- Заканчивай практическим выводом.
- Для сложной темы делай серию коротких роликов, а не один перегруженный.
- Используй единый стиль: цвета, шрифты и ритм появления текста.
